# 暗色候选验收 · 2026-11-13

当前候选分支：`codex/frontend-warp-dark`，基于 `2ce541c`。上一版 `codex/frontend-monochrome` 仍指向 `2ce541c`；原版 `main` 仍指向 `5e1e0e0`。本次只修改前端与交接文档。

## 界面

按 [Warp 参考](https://styles.refero.design/style/d4c51049-58eb-404a-9fcb-f195928b1c99) 使用黑色底、暖白文字、灰色分层面板、20px 卡片圆角与胶囊按钮；紫色用于图标、数据曲线及选中状态，主按钮使用中性灰。借鉴 [Aceternity UI](https://ui.aceternity.com/) 的侧栏、标签与悬停交互，以现有 React/CSS 实现，无新增运行依赖。

桌面侧栏可收起；中等屏幕为图标导航，手机改为横向导航。五项 KPI 分为独立卡片，数据图表和地图沿用真实 API。页面仅保留简短标题、数据和操作；创建菜单、空工作区、模型列表进一步缩减说明文字，不添加宣传标语。

仅暗色：移除主题切换控件、浅色样式和系统主题监听；旧的 `rc.theme=light` 不影响界面，首帧背景和原生控件均为暗色。旧偏好不删除，切回上一候选仍可继续使用其主题设置。

数据口径、未知供给、历史回放、经验区间和「未执行」调配等必要标记继续保留。后端、模型与 HTTP 契约不变。

## 演示

演示文件：`var/frontend-warp/ridecast-demo.mp4`，约 68 秒，1440×1080 / 25fps，H.264，无音轨。以真实浏览器操作展示侧栏、总览筛选、城市回放和 OD、订单、模型、预测调配、任务与系统。

沿用上一版演示的霁川市 45 天合成数据（100,550 个请求）和已训练模型。此演示不代表真实城市业务精度。

截图、原始 WebM、浏览器与 HTTP 检查 JSON 均保存在同目录，未纳入 Git。视频转码显式保留灰度范围，并检查关键帧与完整解码。

## 切换候选

工作区干净时：

```bash
git switch codex/frontend-monochrome  # 上一版候选
git switch codex/frontend-warp-dark   # 当前暗色候选
git switch main                      # 项目原版
```

各分支独立保存；切换代码不删除 `var/` 中的数据、模型和演示。
