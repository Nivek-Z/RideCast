# 前端重构验收 · 2026-11-13

基点：`5e1e0e0`（开始时工作区干净）。范围：`web/` 与前端交接文档；后端、模型和 HTTP 契约保持原有版本。

## 界面

采用 [Vercel 参考](https://styles.refero.design/style/f24daf3a-d43f-4dec-85a9-8ac1d5148a03) 的黑白层级、近白背景、细边框和紧凑组件。借鉴 [Aceternity UI](https://ui.aceternity.com/) 的标签切换、网格和悬停高光，用现有 React/CSS 实现，无新增运行依赖。

七个页面统一为顶部导航和简短页名，去除宣传式标题、英文眉题、说明段落和引导横幅。总览增加当前窗口统计、可点击和键盘选择的区域地图。保留历史回放、模型、预测、订单、任务、系统连接和主题设置。

适配桌面、平板和手机；修复回放时间标签在窄屏右侧溢出。标签支持方向键和 Home/End，弹窗及抽屉支持 Escape 与焦点约束。保留 requests/completed_trips、未知供给、经验区间和未执行调配等必要标记。

## 演示与证据

`var/frontend-redesign/ridecast-demo.mp4`：约 71 秒，1440×1080 / 25fps，H.264，无音轨。实际浏览器操作，含简短章节标注，展示总览、城市回放、订单、模型、预测与调配、任务、深浅主题。

演示使用现有霁川市 45 天合成数据（100,550 个请求）和真实已训练模型；并非真实城市业务数据，也未重新追逐测试指标。视频已检查画面和完整解码，转换时显式保留录屏的完整灰度范围。

同目录包含 `browser-smoke.json`、`http-smoke.json`、页面截图、原始 WebM 与视频抽帧。大体积产物均留在忽略的 `var/`。

## 回退

前端改动单独保存在 `codex/frontend-monochrome` 分支，原 `main` 保留基点。工作区干净时可运行 `git switch main` 回到原界面，也可对本次独立提交执行 `git revert <提交号>`。回退代码不会删除 `var/` 中已有数据和演示。
