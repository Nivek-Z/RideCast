# 数据校准的虚拟世界：后续探索结果

日期：2026-11-17（Asia/Shanghai）。这是在用户授权真实训练区校准之后的后续实验，前一轮负面结果继续保留。

**找到了更有希望的静态空间方案。** 原始未校准虚拟世界迁移的TV为51.34%；真实开发区选出的平滑Poisson加性模型为26.27%；以该模型校准生成器、只用生成标签拟合的学生为25.89%。后两者基本接近，0.38个百分点的差异不足以证明合成训练额外增益。

**不是小时订单“误差率25.89%”，也不是准确率74.11%。** TV衡量区域行程份额分布差异：`50×Σ|真实份额−预测份额|`，0最好、100最差。它表示使两种分布一致所需重新分配的总量比例，不衡量未知统计期的绝对总量或未来时间预测。

## 能回答和不能回答的问题

老师文件只有795区静态属性、累计行程数和未声明投影的区域几何。没有时间戳、统计期、请求/取消或供给记录。本轮回答：能否从真实开发数据学得较稳定的空间关系，并让生成数据保留其预测能力。**不能据此验证GRU小时预测、未来城市增长、现实调度或满意度。**

初检和前轮已看过全文件统计、相关性及测试结果。本轮保留同431个测试区，所有拟合和新增方案选择在训练/开发数据中完成，且评分前保存选择；但仍是**重复使用同文件的探索性研究，不是新独立盲测**。需要新的城市或统计期正式确认。

## 第一阶段：稳健规则校准，保留失败和对照

原开发364区按空间块再分276训练、88验证，原431测试区不进入拟合。比较common3/context6特征与三个固定正则强度，空间块bootstrap40次筛选符号和幅度稳定的关联。最终保留人口、就业密度，面积被排除：

`区域权重 ∝ (1+人口/2732)^0.965 × (1+就业密度/2.6985)^0.904`

参考量固定于训练区，密度单位仍需来源确认；式子不依赖当前待预测区域集合均值、区域ID或固定总行程数。这是条件关联，不是因果定律；两项bootstrap方向同号率均100%，人口系数10%–90%范围约0.60–1.56，幅度不确定性仍明显。

生成192个虚拟世界、12,288个静态区域样本；同一个二次岭回归学习器对比真实、生成及混合训练：

| 方案 | 88区验证TV | 431区探索性对照TV |
| --- | ---: | ---: |
| 均匀分配 | 62.95% | 51.62% |
| 就业密度权重 | 30.86% | 38.75% |
| 原始虚拟世界迁移 | 63.76% | 51.34% |
| 校准规则直接预测 | 24.64% | 40.14% |
| 真实数据训练二次模型 | 34.11% | 37.44% |
| 保守规则生成数据训练（验证区选中） | 17.80% | 40.28% |
| 真实＋生成数据混合（二次模型） | 34.62% | 36.34% |

此阶段按验证区选中纯生成训练模型，测试40.28%，较未校准51.34%改善，但未优于真实直接训练37.44%。混合模型测试36.34%较低，却未由验证区选中，不能事后据测试排名改报它为最终优胜方案。规则噪声尺度在保守拟合中触及预设上限，提示简化规则仍未解释大量真实异质性。

## 第二阶段：开发区内继续找方案

按用户继续探索的要求，使用原364开发区做8个空间块留一验证，比较25个预先固定的候选。包含3/6/15特征的Poisson计数模型、平滑样条加性模型、受人口/就业正向单调约束的提升树、稳健幂次模型和真实/生成/混合训练对照。

所有参考量、缩放和结点均由每折训练部分拟合。排名使用折平均TV加0.25倍折标准差。另在80%样本、5个固定种子重训后要求平均分布变化≤5个百分点、最大≤10，并要求至少6/8折优于就业密度、平均TV相对改善至少10%。这些是研究筛选条件，不是可靠性保证。

开发区自动选中 `spline_15_a1.0`：15个真实外生属性、三次样条、每特征4结点、L2正则alpha=1。排除ID、坐标预测器、拼车计数/比例、行程均价/时长/里程等目标相关字段。其开发折平均TV为21.13%，合并OOF为21.35%，8/8折优于就业密度。

一个空间块仅2区，其他块也不均衡，折平均不可视作8个独立城市。只看其余7个至少10区的折，选中模型平均TV为24.12%，就业密度为35.35%；这是报告诊断，不重新选择模型。

| --- | ---: | ---: | ---: |
| employment_density | 31.46% | 0.00 | 38.75% |
| monotone_boost_poisson_leaf15 | 23.82% | 6.00 | 26.97% |
| poisson_15_a0.1 | 22.22% | 3.68 | 27.79% |
| real_quadratic | 31.50% | 6.41 | 36.74% |
| spline_15_a1.0 | 21.13% | 3.11 | 26.27% |

选中平滑模型的80%样本重训平均分布变化3.11个百分点、最大3.70；总标签乘2/10后的份额变化接近数值精度，追加预测记录对旧记录仅有浮点舍入级差异。**没有验证未来时间漂移，也没有证明数据增长到任何规模都不会失效。**

## 第三阶段：把更强的平滑模型放入生成器

教师取第二阶段的开发区自动选择结果，不按测试成绩手工更换。生成器从364个开发区学习15个属性的联合分布，以教师预测为均值、训练残差MAD为噪声尺度，生成192个虚拟世界、12,288个区域。噪声尺度约0.777，采用均值保持的对数正态和Poisson假设，不声称它们是恢复出的真实动态过程。

学生保留教师的特征变换、参考量、样条结点和缩放，**仅回归系数由9,216个生成区域标签拟合**；3,072个生成区域按教师均值验证保真度，选择alpha=0.01。alpha=0候选达到迭代上限而被排除，未放宽条件继续采用。真实标签进入了教师/生成器和预处理，因此整个路线不是不接触真实标签的纯仿真迁移。

| 最终路线 | 431区TV | 排序相关Spearman |
| --- | ---: | ---: |
| 真实开发区直接训练的平滑教师 | 26.27% | 0.7537 |
| 校准生成数据训练的学生 | **25.89%** | 0.7511 |

学生与教师的份额差异为3.91%，排序相关0.9891，说明保留了大部分教师能力。25.89%与26.27%只差约0.38个百分点，没有独立重复或新测试证据证明生成数据更优。合成区域没有增加独立真实信息；该结果更接近**规则蒸馏与可控生成**的成功，而非证实“造更多数据就提升精度”。

生成样本量检查只使用生成验证世界，不使用真实测试标签：2,304样本拟合相对全量学生的分布变化8.49个百分点；4,608样本为4.25；9,216为0。较少生成样本存在蒙特卡洛波动，不能声称扩充与重训完全不改变模型。相同世界/区域编号的分批、重叠和扩充生成可以逐行复现。

## 适用范围、模拟联通与运行质量

训练空间折确定的简化联合近邻距离诊断，在431对照区中标出4区超出阈值。它是无权标准化距离筛查，不是完整AOA算法，未触发提示的区域也不保证可靠；所有431区都保留在主指标中，没有删除难预测区域。

最终学生区域强度已接到9区真实几何的宏观模拟器：432行面板、4,424条合成请求；重叠一天的订单与面板逐行一致。供给减半场景完成量从4,343变成3,801，仅验证规则运作。小时尺度、曲线、天气、供给、取消、OD和乘客仍是模拟假设。地图仍以EPSG:3435作未确认假设，原绝对时间演化未改。

101项测试通过（19个上游弃用警告）、Ruff和pip check通过。API与独立worker的真实TCP HTTP检查68/68通过，另验证了最终校准世界的HTTP导入、排队模拟和仪表盘聚合。隔离服务验证后已关闭。没有运行Docker或远程CI。

macOS/NumPy矩阵乘法出现过浮点状态警告，但输出有限。对选中模型用逐元素求和独立核对，相对预测差约1.1e-15；教师和学生梯度无穷范数分别约3.1e-7和2.1e-7。使用等价求和避免预测警告，记录未收敛候选及其排除，不改变已选模型或测试结果。

## 结论与交付

当前找到的是**较有希望的静态区域热度方案**：真实数据校准、平滑约束和按空间分组评价有效改善了本文件上的探索性表现；生成路线能够保留教师能力。目前没有足够证据声称虚拟数据本身优于直接真实训练，或规则经得住未来功能变化、统计口径变化、供给约束和跨城市迁移。

保留“较稳定”的工程要求：平滑响应、训练参考量固定、生成器和模型版本化、空间分组敏感性检查和适用范围诊断。实际数据超出支持或出现概念变化时需要重新校准，并用新数据评价。现有文件不能完成这项长期验证。
