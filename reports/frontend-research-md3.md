# RideCast 研究工作台交付记录

日期：2026-11-17（Asia/Shanghai）。分支：`codex/research-md3`。

## 改动与实现

默认首页从运行监控改为研究对比。主导航为实验对比、数据划分、规则稳定性、实验记录；原有地图、订单、模型、预测和资源功能保留在时序工具菜单。使用 MUI 7 与 Emotion，显式覆盖 MD3 色彩角色、色调表面、导航、字级、圆角和状态样式。界面为浅色低饱和蓝灰；桌面侧栏、手机底部导航，没有宣传区或装饰性 KPI 卡。

研究快照在 Vite 启动与构建时从两份已提交报告生成，包含四个连续研究阶段。适配器保留阶段分区、逐折均值、缺失指标与源摘要；允许下载的报告通过静态资源提供。构建不读取老师原始文件、逐区预测或模型，生成的 `web/public/research/` 不提交 Git。

对比页支持选择、搜索、来源筛选、排序、分页、TV / 排序相关切换、开发 / 对照分区切换、方案详情、CSV 与报告下载。数据页显示缺失时间信息、阶段对应分区、输入排除项和生成谱系。稳定性页区分当前平滑模型与早期规则，不把敏感性变化写成精度。研究记录与实时任务分开展示；离线显示连接状态，禁用 GRU 提交。

## 边界

本次只改前端与报告适配，不改变仿真、训练或 HTTP 契约。静态研究是已有离线结果的查看入口，尚未接入研究脚本的排队执行。API 计算仍为现有仿真、导入与 GRU 任务。

TV 为空间份额分布差异，不是小时误差率，也不是准确率；生成学生使用的规则包含真实开发数据校准。四个阶段来自同一文件的连续探索，无时间戳、统计期不明、对照区反复查看等限制均保留。样本增长与规模检查不能证明未来规律稳定。

验证环境为本机 macOS 与内嵌 Chromium 浏览器，未验证 Safari、Firefox、远程 CI 或公开部署。
