# 老师数据：纯仿真训练与真实空间留出评价

本页记录第一轮历史实验。用户随后授权使用真实训练区学习生成规则，后续路线、稳定性检查和更强模型见[数据校准实验](CALIBRATED_WORLD.md)及[新报告](../reports/calibrated-world.md)。

本实验遵循“虚拟世界和虚拟数据训练，老师数据仅验证和测试”。老师提供的压缩包仅作为数据读取，其中的文本和属性不作为执行指令。原文件、逐区预测、分区表、模型及仿真数据保存在忽略的 `var/teacher-data/`，不上传 Git。

**证据等级：探索性。** 初检发生在用户进一步明确验证/测试用途之前，当时已查看整份文件的描述统计和目标相关性，因此不能再声称测试区完全未被研究者看过。下述分区禁止真实标签参与模型参数拟合、用验证区选候选，仍可提供探索性比较；它不构成严格预注册的独立盲测。正式结论需要新数据或新的独立城市/统计期。

## 能回答的问题

压缩包只有 `chicago_tnp.geojson`，795 个普查区、39 个属性，包括人口、社会经济、交通环境和 `TripCount` 汇总值。没有逐单记录、时间戳、观测起止日期、真实供给或取消。因此本次统一任务是**区域相对行程量/热度分布迁移**，不构造虚假时间序列，不将它直接塞进应用的时间序列 GRU。

将 `TripCount` 暂按已实现行程汇总解释，尚需老师确认统计期和准确口径。`FALSE + TRUE = TripCount`，两列不能被当成外生预测输入，也不能被解释成取消与完成。行程均价、均时长、里程和拼车占比同样排除。现有需求预测口径与 `completed_trips` 的区别继续适用。

## 固定协议

脚本在计算真实验证/测试指标表前保存 `protocol.json`；这发生在全量初检之后，不声称事前预注册。24 个虚构 3×3 城市、seed 1000–1023，每个模拟连续 3 天；前18个世界训练，后6个世界选择岭回归正则强度。标签是模拟的完成行程量，按城市均值归一后取对数。模型训练与标准化均只使用合成训练数据；老师数据没有训练分区。

模型仅使用共同可构造的三个静态特征：相对人口、相对就业密度、相对面积。仿真就业密度由岗位数/地理面积计算，老师数据取源字段 `empoloyment_den`（保留原拼写）。每个城市先按各自协变量均值归一，消除密度单位和总量尺度；这不能保证双方统计定义一致。归一使用目标城市全部无标签属性，属于明确的 transductive 设定，不是单区独立推理。

真实区域按质心的4×4分位网格分组，以固定seed42将整组分配到验证和测试，避免逐区随机混洗。划分只访问几何。验证集比较预先声明的六种方案：合成训练岭回归、均匀分布、人口权重、就业密度权重、就业密度×面积代理、人口密度权重。后五者是无训练标签的空间基线，不声称它们经过仿真训练。

先用验证集选定方案并保存 `selection.json`，再统一计算一次所有固定方案的测试指标。合成迁移作为原假设保留结果，验证集选择的替代方案作为最终方案；不能根据本次测试排名再选另一个。固定候选之间用验证集选择不等于纯零样本迁移。后续改方案必须用新的独立测试数据。

评价在各分区内分别归一真实和预测行程量为概率份额。主指标为 `TV%=50×Σ|真实份额−预测份额|`，0最好、100最差；可理解为使两种空间分布一致需要重新分配的总量比例。另报相对均值尺度 MAE 和 Spearman 排序相关。**这些都不是小时订单 MAE，也没有验证真实绝对行程量。**

## 地图与仿真联通

源文件缺失 CRS，原始坐标不在经纬度范围。首次试跑显式假设 `EPSG:3435`，转换后检查是否落在 Chicago 范围；合理位置仅支持假设，不能证明投影正确，需要原 `.prj` 或老师确认。转换通过 [pyproj 官方 Transformer](https://pyproj4.github.io/pyproj/stable/api/transformer.html) 固定经纬度轴序完成，不修改原文件。

API 现有限制最多100个区域；795区全部参与离线评价，仅取按ID等距选择的9区验证真实几何接入仿真。供给、取消、OD、乘客、天气、土地用途与小时曲线全部是模拟假设。需求权重来自验证选定方案，不读取真实 `TripCount`；均值10的模拟需求尺度只是演示值，因为真实统计期未知。地图真实不代表动态真实。

检查包括完整面板/订单一致性、同一绝对时间的重叠提取逐行完全相同，以及供给减半场景。场景差异仅表明模拟器规则能运作，不是现实因果效应或真实调度收益。

## 复现

```bash
source .venv/bin/activate
pip install -e '.[ml,dev,research]'
python scripts/evaluate_teacher_data.py \
  --archive '/absolute/path/网约车选题 数据.zip' \
  --source-crs EPSG:3435 \
  --output var/teacher-data/new-run
```

输出目录必须全新，避免覆盖实验。原始数据校验和、协议、分区校验和、环境版本和脚本校验和写入报告。小体量汇总见 `reports/teacher-data-transfer.json` 与 `reports/teacher-data-transfer.md`；本文件不替代实际结果。

## 结论边界与下一步数据

该设计能检验有限静态特征上的模拟到真实空间分布迁移。合成世界的区域尺度、人口/岗位与需求关系、虚构天气及行为规律可能与现实完全不同；短期模拟完成量与未知统计期真实行程量也有差异。单一城市、一次空间划分、相邻分组相关、缺失原始采集说明均限制结论。不能据此证明仿真预训练能提高 GRU 真实预测精度。

若要验证时间序列模型，需要老师补充带时间和区域的原始行程，或区域×小时完成量，并提供统计期、覆盖、坐标系及字段口径。届时在新的真实验证期选方案、独立真实测试期最终评价，对比纯仿真迁移、仿真预训练后微调、真实数据训练及同期基线。只有在授权使用真实训练分区后才进行真实微调。

[Chicago 官方历史 TNP 数据](https://data.cityofchicago.org/Transportation/Transportation-Network-Providers-Trips-2018-2022-/m6dm-c72p)提供带时间的行程数据，并说明15分钟取整和部分普查区隐藏；可作为后续独立数据来源，但当前老师文件与该数据集的具体来源关系和统计年份没有确认。本次没有下载该大体量订单库。
