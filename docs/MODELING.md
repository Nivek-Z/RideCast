# 建模设计、评价与实验边界

## 目标

对区域z预测未来H桶发起请求数。API的forecast_origin为首个预测桶左端，第h步时间为 `forecast_origin+(h-1)×bucket_minutes`，历史严格早于forecast_origin。默认1小时桶、过去24桶、未来3桶，均可配置。合成数据包含完整发起请求；真实数据若只能提供已完成行程，则模型目标明确为completed_trips。乘客数是需求解释变量的历史滞后值，与订单数分开，不把目标时段人数当作已知输入。

## 特征与模型

历史分支包含log1p需求、接触区域历史需求的等权均值再取log1p、log1p历史乘客、温度、log1p降雨、风速、拥堵和log1p供给；孤立区的邻域需求回退到自身。未来分支包括当地小时/周内周期、节假日（含周末与调休）及工作日标志、已公告活动和天气/交通/供给的起点持续假设。静态分支含区域几何质心经纬度、log1p人口、log1p岗位、吸引力和区域one-hot标识。kind与base_demand用于合成需求生成，kind也影响自动公告活动，但当前没有直接编码为模型静态特征。完整有序特征名及版本由model.metadata.feature_schema给出。

共享区域GRU编码历史序列，Dense编码未来已知上下文，拼接静态特征，经Dense和Dropout后用softplus输出未来H步的log1p需求；Adam带梯度裁剪，训练损失为log1p尺度MSE，推理用expm1映射回非负订单量。该值是点预测，不保证严格无偏的算术期望。共享网络适合小样本及不规则区域，邻域特征让首期无需绑定规则栅格；后续可用图卷积替换共享编码器。

不采用固定栅格ConvLSTM作为唯一方案，是因为真实地图可能为不规则服务区；首期也不引入大Transformer或完整图网络，避免参数量与演示成本超过数据规模。相关比较与论文链接见 research-notes.md。

## 信息边界与评估

1. 原始连续时序按70%/15%/15%划分训练、验证、测试。最早lookback桶用于历史，不产生训练标签；每个多步目标窗口必须完整位于所属分区。
2. 同一预测起点只访问严格早于该起点的订单/人数/天气/供给。验证/测试允许使用自身已过去的真实历史，属于滚动起点评价；不会读本次起点以后才知道的状态。
3. 缩放均值/标准差仅由训练窗口拟合并随模型归档。模型未来天气默认使用最后已知值，回测与在线预测复用同一函数；虚拟世界的未来真值可供仿真查看，但不能暗中送给模型。
4. 基线有最近值、前日同期、前周同期；按验证MAE选定主基线。多步需要的同期若尚不可知，继续向过去回退；无足够历史退到最近值。
5. tune=true实际训练两个候选：原配置与更大GRU/更低学习率。训练过程仅在验证损失早停并恢复最佳权重；候选按验证MAE选择。测试只在模型与基线规则确定后最终评估，不通过看测试结果继续挑种子/轮数。

训练时shuffle仅发生于已切好的训练窗口，不随机拆分原始时间。模型版本保存每区/每步指标、候选验证分数、曲线及测试明细。测试分区内多步窗口可以覆盖相同目标时刻，统计单元为forecast_origin×zone×horizon；所有方法使用相同单元，图表不能把这些重复时刻加总为城市需求。

## 指标与区间

MAE为平均绝对误差，RMSE为均方误差平方根（单位订单）；WAPE为绝对误差和除以真实需求和×100%；sMAPE为 `mean(2*abs(y-p)/(abs(y)+abs(p)))*100%`，二者均0时该项为0。真实需求和为0时WAPE返回null。保存的loss/val_loss为log1p尺度，不能与订单尺度MAE混用。

每个预测步用验证集绝对残差90%分位数建立对称经验区间，lower下截0；同时报告测试覆盖率和平均宽度。这不是严格校准的条件置信区间，也不是同时覆盖所有区域/时刻的保证；时间依赖和分布变化会改变覆盖。未使用测试残差调整区间。

## 实际结果

完整演示为seed42、3×3城市、45天、100,550发起请求、9,720个区域时间桶；两个候选各最多12轮，由验证集选择。测试4,320个区域/起点/步长预测单元：GRU MAE **3.1886**、RMSE **4.5194**、WAPE **41.01%**；验证集选定主基线为前周同期，测试MAE **4.8366**。所有基线也保留：前日同期在该测试集MAE **3.4801**，因此报告相对主基线34.07%的改进时必须一并说明，不能将其当作优于所有基线34%。区间测试覆盖率 **89.05%**。细节在 `reports/demo.json`。

三种随机世界各28天、同一小模型配置5轮独立重训：模型平均MAE **3.4736**，基线平均 **3.3265**，只有1/3世界优于其验证集选定基线。这个结果提醒模型并非总优，较少种子和短训练只提供有限证据。此实验测试生成器下重复建模稳定性，未评价单个模型跨城市零样本泛化。完整结果与源码复核记录见 `reports/world-benchmark.md` 和JSON。

## 后续实验与真实部署

正式研究可增加更多预先指定种子与时间段、滚动起点交叉验证、稀疏区域及高峰分组、极端天气和活动压力测试、邻域/天气/日历消融，以及供给干预前后离线调配评价。应在新开发集上选方案，再用保留的未见测试区间验证，不能反复追当前测试分数。

合成宏观演化没有经过城市真实分布校准，不支持宣称提升真实出行满意度、降低真实空驶率。调配仅为启发式建议，没有真实执行或交通路径约束。接入真实请求、取消、供给、天气预报及公告活动后，还需数据覆盖检查、漂移监控和真实时序回测，再决定模型启用。
