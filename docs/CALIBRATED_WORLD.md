# 数据校准的虚拟区域与稳定性探索

本轮由用户明确授权：先从老师数据的**真实训练/开发区**提取关系，再生成虚拟数据训练模型。与[第一轮纯仿真迁移](TEACHER_DATA.md)不同，生成器现在确实使用了真实训练标签；不得再称为完全不接触真实标签的零样本迁移。

最新结果见[完整报告](../reports/calibrated-world.md)与[汇总JSON](../reports/calibrated-world.json)。有希望的平滑模型由真实开发区选择；其规则生成的虚拟数据可以训练出表现接近的学生模型。本轮没有证实合成数据比直接真实训练提供可靠的额外精度。

## 数据与证据等级

只有795区静态属性和累计 `TripCount`，无统计期或时间序列。本轮仍预测区域累计行程的**相对空间分布**，不构造假的真实小时标签，不接入 GRU 小时预测接口。行程量暂按已实现行程解释，不能推断取消、潜在请求或真实供给。

初检和前轮实验已查看全量描述统计、相关性和测试结果。本轮继续使用同一文件，是**探索性后续研究**，不是新的独立盲测。每阶段在计算其测试指标前保存选择记录，新增方案选择和模型拟合都在开发数据中完成；这些措施无法消除之前看过测试集的影响。确认效果需要新城市、独立统计期或新的未见数据。

## 三个阶段

1. **保守规则校准。** 保留原431个测试区，将前轮364个验证区再按整块划成276个训练区、88个验证区。从人口、就业密度、面积及少量环境变量拟合平滑稳健规则，训练空间块bootstrap40次，排除方向或幅度不稳定的项。人口和就业密度被保留。真实标签只拟合训练区；验证区选规则及学生模型。生成192个虚拟世界、12,288个静态区域样本，对比同一二次岭回归学习器的真实训练、纯生成训练和混合训练。
2. **开发区扩展搜索。** 在原364个开发区内，以8个空间块留一交叉验证比较25个固定候选：Poisson计数回归、平滑样条加性模型、人口/就业单调约束的提升树、稳健幂次规则、同结构真实/虚拟/混合训练和简单基线。变换、参考量、缩放、样条结点和生成规则仅由每折训练区拟合。以折平均TV加0.25倍折标准差排名，先保存选择，再对431区作最终探索性比较。
3. **平滑规则生成与蒸馏。** 取上一步由开发区自动选定的样条Poisson模型作为生成均值规则，学习开发区联合协变量分布和残差尺度，生成192个虚拟世界、12,288个区域样本。9,216个生成区域拟合学生系数，3,072个生成区域按教师均值评价保真度、选择学生正则强度。真实标签不再进入学生系数拟合，但其特征变换/样条结点、生成器及教师均来自真实开发区。

各阶段的测试区相同，训练区规模和方法不同。完整报告同时给出直接真实训练对照，不能将阶段间的全部提升都归因于“生成更多数据”。

## 稳定规则如何处理

第一阶段的规则采用 `w ∝ ∏(1+x_j/reference_j)^β_j`，参考量固定为训练区正值中位数；没有区域ID、固定总行程数或按某个区域硬编码的规则。Huber残差加权与岭正则控制拟合，斜率限制在[-2,2]。仅保留空间块bootstrap中同号比例至少90%、相对系数IQR至多1、系数中位数绝对值至少0.05的项。它们是关联方向筛选，不是因果或长期不变规律。

后续更强模型用三次样条表示连续平滑关系，每特征仅4个结点，使用L2正则。Poisson采用对数链接拟合条件均值；数据可能过度离散，不能据此假定真实方差严格等于均值。提升树作为对照施加人口/就业密度单调约束；该约束不是已证明的社会规律。

扩展搜索另设开发区稳定性筛选：按空间块内抽取80%样本、5个固定种子重训，预测分布相对全量拟合平均TV不超过5个百分点、最大不超过10个百分点。候选还需在至少6/8折优于就业密度基线，折平均TV至少相对改善10%，才标为有希望。阈值是声明的研究筛选条件，不是产品准确率保证。

检查总行程量整体乘2/10后份额是否保持、追加新待预测记录是否改变旧记录输出，以及生成样本从2,304增至4,608/9,216时学生的变化。总量倍增的不变性部分来自模型设计，不能把它当作未来行为变化的实证验证。人口变化、城市功能改变、供给限制或统计口径改变仍可能使规则失效。

一个开发空间块只有2个区域，其余块规模也不均衡。折平均评价受小折影响，报告同时保留逐折与合并OOF指标，不将8折描述为8个独立城市。联合特征近邻距离只提供超出训练支持的提示，并未完整复现文献中的加权AOA，也不能保证未触发提示的预测可靠。

## 生成器与原有世界的关系

新生成器是**静态虚拟区域生成器**。协变量来自训练区拟合的收缩联合对数分布，在训练边界内采样；标签均值来自学到的规则，残差噪声由训练残差MAD估计并采用对数正态/Poisson假设。样本数量不是独立真实观测数量。联合分布近似、噪声形态和虚拟世界间依赖都尚未获真实动态数据验证。

版本分别为 `calibrated-spatial-world-v1`、`spatial-model-search-v1` 和 `calibrated-gam-spatial-world-v1`。校准配置、训练参数、模型文件和源文件校验和记录在忽略目录；按版本/种子/世界编号/区域编号锚定随机数，相同编号的重叠、分批、扩充提取能复现。

还将最终学生的区域强度接到原宏观模拟器，使用老师9区几何，验证订单/面板与重叠时间一致。地图源CRS仍显式假设 `EPSG:3435`，需要原 `.prj` 确认；模拟小时强度的总体尺度、小时曲线、天气、供给、取消、OD和乘客仍是演示假设。**没有把未知统计期累计行程量当成每小时真实需求。** 原 `absolute-time-v2` 时序演化未改，API/OpenAPI和既有GRU模型生命周期未改。

## 复现与产物

Python3.11/3.12，保持TensorFlow/Keras/NumPy/PyArrow原有兼容版本。新增研究依赖均为可选 `research` extra。

```bash
source .venv/bin/activate
pip install -e '.[ml,dev,research]'
# 先按TEACHER_DATA.md生成第一轮transfer-v1产物，再顺序运行：
python scripts/evaluate_calibrated_world.py --archive '/absolute/path/网约车选题 数据.zip' \
  --source-crs EPSG:3435 --output var/teacher-data/calibrated-v1
python scripts/explore_spatial_models.py --archive '/absolute/path/网约车选题 数据.zip' \
  --source-crs EPSG:3435 --output var/teacher-data/spatial-search-v1
python scripts/distill_calibrated_world.py --archive '/absolute/path/网约车选题 数据.zip' \
  --source-crs EPSG:3435 --output var/teacher-data/gam-world-v1
```

每个输出目录必须全新。原始输入、分区、逐区预测、合成区域、注册表、模型、警告日志和实际运行源码快照留在忽略的 `var/teacher-data/`；Git仅包含代码、协议、文献笔记和小体量汇总。数值等价修正、后续检查与原评分分别留有校验和，不因代码整理而重新挑选测试结果。
